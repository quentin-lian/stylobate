新增三个包：

- `@stylobate/icons`：基于 Lucide 的图标库，支持 React 与 Vue 双框架，内置自定义 SVG codegen 管线
- `@stylobate/ui-react`：React UI 组件库（Radix UI + Tailwind CSS），首版包含 Button / IconButton / ButtonGroup，附带 design tokens 与 a11y 测试
- `@stylobate/ui-react-cli`：CLI 工具，`stylobate-ui init` 初始化项目，`stylobate-ui add <component>` 按需添加组件
